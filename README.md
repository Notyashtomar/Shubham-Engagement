# Shubham & Sunaina – Engagement Ceremony

A mobile-first digital engagement invitation built with React, Vite and Motion.

## Editing the details

All names, dates, venue, contact numbers, music and image paths live in `src/weddingConfig.js`.

## Development

```bash
npm install
npm run dev      # local server
npm run build    # production build in dist/
```

## Artwork

Source artwork is in `assets-src/`. After replacing any of it, run `npm run assets` to regenerate the optimised files in `public/images/`.
